virtual void zero_mate::peripheral::ISystem_Clock_Listener::Increment_Passed_Cycles ( std::uint32_t count)
pure virtual

Notifies the peripheral about how many CPU cycles have passed by.

The CPU core calls this function after every instruction, so the peripheral can update itself. Every class/struct that inherits from the ISystem_Clock_Listener class must implement this function.

Parameters
countNumber of CPU cycles

Implemented in zero_mate::peripheral::CARM_Timer, zero_mate::peripheral::CAUX, and zero_mate::peripheral::CBSC.
