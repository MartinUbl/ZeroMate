template<typename Reg_Type>
std::shared_ptr< Reg_Type > zero_mate::coprocessor::cp15::CCP15::Get_Primary_Register ( NPrimary_Register primary_reg) const
inlinenodiscard

Returns a primary register of a given type.

All primary registers are held by this class as IPrimary_Reg, which they all inherit from. When the caller function wants the access a primary register of its actual type, it needs to pass the type as a template.
